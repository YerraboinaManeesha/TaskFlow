# TaskFlow

**TaskFlow** is a full-stack task management web application designed to help users organize projects, manage tasks, and track their work through a clean and intuitive dashboard.

## 🚀 Live Demo

[**Open TaskFlow**](https://taskflow-app-8b7p.onrender.com)

## ✨ Features

* 🔐 User registration and login
* 🔑 Forgot password and password reset
* 📊 Personalized dashboard
* 📁 Create and manage projects
* ✅ Create, manage, and delete tasks
* 👤 User-specific project and task management
* 🔗 RESTful API integration
* 📱 Responsive user interface
* ☁️ Cloud deployment using Render

## ⚙️ Getting Started

### Prerequisites

* Node.js
* npm
* Git

### Installation

Clone the repository:

```bash
git clone https://github.com/YerraboinaManeesha/TaskFlow.git
```

Navigate to the project:

```bash
cd TaskFlow
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will normally run at:

```text
http://localhost:5173
```

## 🔗 Backend Configuration

TaskFlow uses a FastAPI backend and communicates through RESTful APIs.

Configure the frontend with the backend API URL using an environment variable:

```text
VITE_API_URL=YOUR_BACKEND_API_URL
```
